Devicon only accepts Icons of development/programming languages and technology.

**Development** refers to programming or programming-related jobs.

**Technology** can be software, OS, services, etc. that helps with development. It must be closely related to development and not too general to public use. 

**Example:** Programmers commonly uses Microsoft Word. However, its usage is not specific to the programming industry. Therefore, it will not be accepted.

Thus, before you request/add a new icon, please check these criteria:
- Is your icon relatively well-known? A brand new tech that hasn't been adopted yet is unlikely to be accepted.
- Is the technology also commonly used outside of development jobs? Software like Microsoft Word or Google Calendar won't be accepted since it's too general and not specific to development jobs.
- Can you:
  1. Write code with it?
  2. Handle code with it?
  3. Transform code with it?
  4. Add your code to it?
  5. Test you code with it?
- Does the logo belongs to a more general parent company? For example, React is a part of Facebook. Using the Facebook logo to represent React is not accepted.

## Special Cases (see [this discussion](https://github.com/devicons/devicon/discussions/353) for more details)
- Tech companies used to be accepted in the repository. However, we do not accept them anymore. Icons like Facebook, Twitter, etc., are kept for backward compatibility.
  - We still accept their icons if they represent a service and not the company itself.
  - Ex. AWS is accepted since their names refer to their cloud services. However, we will not accept Amazon since Amazon as a whole includes non-tech related services.
- Related fields like graphic designs or game development. Since many "development" jobs require people to know related fields, some software will be accepted in Devicon even though they aren't strictly "development tools".
  - ex. some Adobe products (Photoshop, Aftereffects), game engines (Unity, Unreal), CMS (Shopify), etc... See [this](https://github.com/devicons/devicon/pull/336) for more details.
- General tools that are well known in the tech industries. Things like Trello, Slack, etc., are accepted under this category. Unfortunately, we won't accept Discord since its use is still too general. This will be treated on a case-by-case basis.

## In-depth List of Categories

Here are the categories that we usually accept/don't accept in our repos. If you would like to change our mind, please open a discussion. Thanks to [Ben Souchet](https://github.com/devicons/devicon/discussions/353#discussioncomment-1979491) for creating the original list.

### Allowed
- [Operating systems](https://en.wikipedia.org/wiki/Operating_system) (Linux, MacOS, Windows, ...)
- [Programming languages](https://en.wikipedia.org/wiki/List_of_programming_languages) (C, C++, Python, ...)
- [CLI languages](https://en.wikipedia.org/wiki/List_of_CLI_languages) (PowerShell, Swift, Visual Basic, ...)
- [Command-line interpreters](https://en.wikipedia.org/wiki/List_of_command-line_interpreters) (Unix Shell, zsh, bash, ...)
- [Compilers](https://en.wikipedia.org/wiki/List_of_compilers) (GCC, LLVM, Clang, ...)
- [IDEs](https://en.wikipedia.org/wiki/Comparison_of_integrated_development_environments) (Visual Studio, PyCharm, Xcode, Atom, ...)
- [Markup languages](https://en.wikipedia.org/wiki/List_of_document_markup_languages) (HTML, LaTeX, XML, Markdown, ...)
- [Style sheet languages](https://en.wikipedia.org/wiki/Style_sheet_language) (CSS)
- [Style sheet preprocessors](https://www.envato.com/blog/css-preprocessors/) (Less, Sass, SCSS, Stylus, ...)
- [Packages managers](https://en.wikipedia.org/wiki/List_of_software_package_management_systems) (npm, bower, Homebrew, NuGet, ...)
- [Database programs & systems]() (MangoDB, MySQL,SQLite, ...)
- [Database tools](https://en.wikipedia.org/wiki/Comparison_of_database_administration_tools) (phpMyAdmin, pgAdmin, ...)
- [Software Frameworks](https://en.wikipedia.org/wiki/Software_framework) (Electron, Qt, ...)
- [Web Frameworks](https://en.wikipedia.org/wiki/Comparison_of_server-side_web_frameworks) (Django, Angular, ...)
- [Runtime environments](https://en.wikipedia.org/wiki/Runtime_system) (Node.js, ...)
- [Web server softwares](https://en.wikipedia.org/wiki/Comparison_of_web_server_software) (apache, nginx, ...)
- [Source code hosting platforms](https://en.wikipedia.org/wiki/Comparison_of_source-code-hosting_facilities) (Github, Gitlab, Bitbucket, ...)
- [Testing tools](https://en.wikipedia.org/wiki/Software_testing) (Jasmine, )
- [Static Site Generators](https://en.wikipedia.org/wiki/Web_template_system#Static_site_generators) (Jekyll, Hugo, eleventy, ...)
- [Web browsers](https://en.wikipedia.org/wiki/List_of_web_browsers) (Google Chrome, Mozilla Firefox, Microsoft Edge, ...)
- [OS-level virtualization](https://en.wikipedia.org/wiki/OS-level_virtualization) (Docker, chroot, ...)
- [FTP Client Softwares](https://en.wikipedia.org/wiki/Comparison_of_FTP_client_software) (Filezilla, WinSCP, ...)
- Popular modules, packages, libraries (Babel, Tensorflow, Jupyter, ...)

### Need Discussions
For these categories we need to examine how it's related to development before accepting.
- [Content management systems (CMS)](https://en.wikipedia.org/wiki/List_of_content_management_systems) (Wordpress, Drupal, Prestashop, ...). Some are too general.
- [Raster graphics editors](https://en.wikipedia.org/wiki/Raster_graphics_editor) (Photoshop, GIMP, ...)
- [Prototyping tools](https://en.wikipedia.org/wiki/Comparison_of_vector_graphics_editors) (Figma, Adobe XD, Sketch, Pencil, ...)

### Not Allowed (not exhaustive)
- [Social Media platforms](https://en.wikipedia.org/wiki/List_of_social_networking_services) (Facebook, LinkedIn, Twitter, ...)
- [Email marketing Services](https://en.wikipedia.org/wiki/Email_marketing) (Mailchimp, ...)
- [CRM tools](https://en.wikipedia.org/wiki/Customer_relationship_management) (Salesforces, ...).
- [Project management tools](https://en.wikipedia.org/wiki/Project_management) (Jira, Monday, ClickUp)
- [Internet providers](https://en.wikipedia.org/wiki/Category:Internet_service_providers_by_country) (AT&T, Verizon, ...)
- [Web hosting platforms](https://en.wikipedia.org/wiki/Category:Web_hosting) (Hostinger, Bluehost, SiteGround, ...)
- [General Website builders](https://en.wikipedia.org/wiki/Website_builder) (Wix, Squarespace, ...)
- [Computer-aided design tools](https://en.wikipedia.org/wiki/Computer-aided_design) (AutoCAD, Solidworks, SketchUp, ...)
