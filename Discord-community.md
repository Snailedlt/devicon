We're running a Discord community maintained by the whole Devicon team.
You can discuss, talk, make suggestions, request icons, and more. This is mostly if you don't have a GitHub account or simply want to hang out with the community members.

We're also using [GitHub Discussions](https://github.com/devicons/devicon/discussions) for similar things, but if you want to have less professional talks or questions, Discord is the right place for you to come.
Please note that if you have a GitHub account and want to request an icon, it is best to do so in our issue tracker rather than in our Discord community.
