To make it easy to find the SVG files in the repository, please follow these standards:

![Organization Rules Img](https://github.com/devicons/devicon/blob/2853520419a122fa53e5ca110b3aac0fc172a5f5/docs/wiki/organization_rule.PNG)

*   Each technology has its own folder located in the `icons` folder.
*   All the `.svg` files for the Icon must go in the same folder.
*   _Optional_: Each folder _may_ contain one `.eps` file. The `.eps` file should contains all available versions of an icon. Each version is contained in a 128px by 128px artboard.
