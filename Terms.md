<h3 id="terms">Terms</h3>
<p>Here are some terms that we will use in this repo: </p>
<ol>
  <li>"Technology" is used to describe any software, libraries, tool, programming languages, etc... related to the programming industry.</li>
  <li>"Icon" refers to the SVGs and icons version of a technology as a whole.</li>
  <li>"SVG/<code>SVG</code>" refers to the <code>.svg</code> versions of the Icons.</li>
  <li>"icon" (lowercase) refers specifically to the font icon versions of the Icons.</li>
</ol>
