<p>To request an icon, please create an issue in the repository, and follow these guidelines:</p>

<b>Note:</b> Create a separate issue for each icon.

<ul>
  <li>Search for existing issues with your icon name.</li>
  <li>If an issue doesn't exist, create a new issue using our Issue Form.</li>
  <li>Use the Issue Template and fill out the proper information</li>
  <li>Please include links where the icon can be found if possible. Ex: the icon's official webpage/wiki article.</li>
</ul>
